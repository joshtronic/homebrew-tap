# joshtronic's Homebrew tap

```sh
brew install --cask joshtronic/tap/hautekey
brew install --cask joshtronic/tap/dinkycal
```

| Cask | What it is |
|---|---|
| [hautekey](https://hautekey.app) | Your Mac's right ⌘ as a Hyper key: tap for Spotlight, hold for apps and window snapping. |
| [dinkycal](https://dinkycal.com) | A gnome-sized month calendar in your menu bar, with busy days shaded by hours booked. |
